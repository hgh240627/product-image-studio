## 免费更新托管方案

推荐使用 GitHub Releases + GitHub raw 文件。项目已经内置 `.github/workflows/release.yml`，连接 GitHub 仓库后可以自动发布 Release 并更新 `update.json`。

1. 在 GitHub 新建一个公开仓库，例如 `product-image-studio-updates`。
2. 把本地仓库推送到 GitHub。
3. 推送版本标签，例如 `v0.1.53`，GitHub Actions 会自动打包、上传 Release、生成 `update.json`。
4. 直接使用 raw 地址：
   `https://raw.githubusercontent.com/<用户名>/<仓库名>/main/update.json`
5. 在软件设置里填写这个 `update.json` 地址，并勾选“启动时自动检查新版本”。

软件不会强制更新。检测到 `latestVersion` 大于当前安装版本时，只会提示：

- 立即更新：打开 `downloadUrl`
- 稍后提醒：本机 12 小时内不再自动弹出
- 查看更新内容：打开 `releaseNotesUrl`，如果没有链接则显示 `notes`

## update.json 模板

```json
{
  "latestVersion": "0.1.53",
  "title": "v0.1.53",
  "summary": "修复设置弹窗层级问题，并加入非强制更新提醒。",
  "downloadUrl": "https://github.com/<用户名>/<仓库名>/releases/download/v0.1.53/product-image-studio-0.1.53-Windows-x64.exe",
  "releaseNotesUrl": "https://github.com/<用户名>/<仓库名>/releases/tag/v0.1.53",
  "publishedAt": "2026-06-03",
  "notes": [
    "修复设置内获取模型列表/检测结果弹窗被设置面板遮挡的问题。",
    "加入发现新版本、立即更新、稍后提醒、查看更新内容。",
    "AI 工作台生图预览支持保存图片。"
  ]
}
```

发布下一版时，如果使用 GitHub Actions，不需要手动修改 `update.json`；只需要更新 `package.json` 版本号并推送对应标签。
